# SAWT Application

## Project Structure

The project structure for the SAWT application is organized into the following folders:

```
SAWT/
├── frontend/      # Contains frontend application code
│   ├── src/      # Source files
│   ├── public/   # Static files
│   ├── tests/    # Frontend tests
│   └── README.md  # Frontend documentation
│
├── backend/       # Contains backend application code
│   ├── src/      # Source files
│   ├── tests/    # Backend tests
│   ├── config/   # Configuration files
│   └── README.md  # Backend documentation
│
├── mobile/        # Contains mobile application code
│   ├── src/      # Source files
│   ├── tests/    # Mobile tests
│   └── README.md  # Mobile documentation
│
└── documentation/  # General project documentation
    ├── architecture.md  # Architecture design
    ├── setup.md         # Setup instructions
    └── user_guide.md    # User guide
```

## Notes
- Each folder contains a README file for specific documentation.
- Test folders are included for each application type to facilitate unit testing.
- General documentation is in the `documentation` folder, summarizing the architecture and setup processes.
